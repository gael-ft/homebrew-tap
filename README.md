# Gael-ft Tap

## How do I install these formulae?

`brew install gael-ft/tap/<formula>`

Or `brew tap gael-ft/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gael-ft/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
